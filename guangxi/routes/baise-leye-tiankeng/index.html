骑行节奏 · 结伴纪律

中途休息节奏

按每 100 公里或 50 分钟驾驶强度安排一次休息，不硬撑疲劳里程。

集结点约定

每 20–30 公里约定一个集结地，清点人数、补给与休息后再统一出发。

队形与车距

不同车道错开行驶，避免同车道跟车过近；保持稳定车速与足够刹车距离，防追尾碰撞。

防掉队与次序

超短途结伴尤其注意掉队与次序，设领队与收尾、保持可视距离，路口等齐不擅自超车。

路线路径

百色城区边缘 → 省道北上凌云县 → 继续北上乐业县 → 同乐镇大石围天坑群景区 → 原路返回。

目的地介绍

看点

大石围天坑位于乐业县同乐镇刷把村，形成于白垩纪，垂直深度613米、东西长600米、南北宽420米，为世界第二大天坑；天坑底部有原始森林与地下暗河，坑口云雾缭绕如仙境；周边分布罗妹莲花洞、穿洞等20余个天坑，为全球最大天坑群。

历史

大石围天坑1998年被中外探险队正式确认；乐业天坑群2005年被联合国教科文组织评为世界地质公园。

人文

乐业县壮族与苗族聚居，苗族芦笙舞与壮族山歌为在地文化；乐业野生山茶与猕猴桃为特产。

故事与趣事

探险摩友把乐业天坑叫"百色骑行终极目标"——站在坑口边缘往下看的那一刻"腿软但值得"；老手提醒"全程200km必须两天，凌云住一晚或乐业住一晚；乐业海拔约1100米，秋冬清晨大雾弥漫，能见度可能不到20米，务必慢行"。

注意事项

  • 百色右江区核心城区全天禁摩，外围县份（凌云/乐业/靖西/德保）基本开放，2026年4月后实行"清单化"管理；本库路线从城区边缘出发，进入县道后自由骑行，出发前以当地交警最新通告为准
  • 本线约 176km，单箱油难以往返：凌云/乐业/靖西/德保县城均有中石化/中石油，进山前在县城加满、镇上补满
  • 广西全省高速公路入口设禁摩标志、严禁驶入，本库路线全程按国道/省道/县乡道规划；百色山区弯多坡陡，出发前以高德实况与当地交警发布复核
  • 3C认证头盔必戴，建议护膝手套齐全；百色山区雨季（5-9月）路滑雾大，落石与积水路段现场判断、不抢行；天坑/峡谷边缘注意安全护栏
  • 乐业大石围全程约200km需两天一夜，凌云或乐业县城住宿补给；山区弯多坡陡、海拔变化大，新手勿单独挑战；天坑边缘注意安全护栏，勿翻越。
