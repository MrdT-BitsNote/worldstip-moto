RIDE DISCIPLINE

骑行节奏 · 结伴纪律

本线约 132km · 建议 5 个集结点 · 约 3 次中途休息

中途休息节奏

按每 100 公里或 50 分钟驾驶强度安排一次休息，不硬撑疲劳里程。

集结点约定

每 20–30 公里约定一个集结地，清点人数、补给与休息后再统一出发。

队形与车距

不同车道错开行驶，避免同车道跟车过近；保持稳定车速与足够刹车距离，防追尾碰撞。

防掉队与次序

超短途结伴尤其注意掉队与次序，设领队与收尾、保持可视距离，路口等齐不擅自超车。

路线路径

南宁市政府广场 → G210国道北上 → 武鸣区 → 两江镇 → 大明山盘山公路 → 大明山景区 → 原路返回。

目的地介绍

看点

大明山位于武鸣区两江镇，主峰龙头山海拔1760米，为桂中南最高峰；盘山公路蜿蜒至山顶，沿途瀑布溪流、原始森林，山顶可观云海日出与万亩高山杜鹃。

历史

大明山古称"大鸣山"，壮语意为"大山"；历代为桂中南名山，道教与壮族民间信仰圣地。

人文

大明山区域壮族聚居，壮族龙母文化与摩教信仰深厚；每年农历三月初三壮族歌圩盛况空前。

故事与趣事

广西摩友把大明山当"南宁摩旅成年礼"——与柳州元宝山、桂林海洋山并称"广西三大跑山"；山顶杜鹃花期3-4月最盛，云海要看运气（秋冬清晨概率最高）；老手提醒"武鸣加满油，山上无加油站；盘山段上坡靠右、不借道"。

注意事项

  • 南宁绕城环道内全天禁摩（2024年5月施行，有效期5年），外地牌严禁驶入绕城环道，违规罚200元；本库路线均在绕城环道以外规划
  • 本线约 132km，单箱油难以往返：武鸣/上林县城均有中石化/中石油，进山前在县城加满
  • 广西全省高速公路入口设禁摩标志、严禁驶入，本库路线全程按国道/省道/县乡道规划；出发前以高德实况与当地交警发布复核
  • 3C认证头盔必戴，建议护膝手套齐全；南宁雨季（5-9月）路滑雾大，山区落石与积水路段现场判断、不抢行
  • 大明山盘山段弯多路窄、会车困难，新手勿单独挑战；春季杜鹃花期（3-4月）山顶停车拥堵；山上无加油站，武鸣必须加满。
