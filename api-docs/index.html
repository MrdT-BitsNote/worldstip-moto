快速开始

两步接入：先取索引，再按需加载省份数据。

① 获取全国索引

// 索引包含全部省份的代码、数据文件路径与数据量
const index = await (await fetch('https://moto.worldstip.com/map-data/index.json')).json();

// 实际返回结构（数值取自本次构建）：
{
  "generated": "2026-10-24",
  "totalRoutes": 1713,
  "totalWaypoints": 5022,
  "totalCities": 360,
  "provinces": [
    { "name": "湖南省", "code": "hunan", "file": "provinces/hunan.json",
      "routes": 201, "cities": 14, "sizeKB": 1934 },
    // ... 共 31 个省份
  ]
}

② 按需加载省份数据

// 用索引返回的 file 路径加载（推荐），也可直接拼 code
const hunan = await (await fetch('https://moto.worldstip.com/map-data/provinces/hunan.json')).json();
console.log(hunan.routes.length, '条路线', hunan.routes[0].p.length, '个轨迹点');

Python 示例

import requests

index = requests.get("https://moto.worldstip.com/map-data/index.json").json()

接口一览

纯静态文件，可被任意 CDN 缓存。无鉴权、无频控。服务端（Python / Node / Go / curl）可直接调用；浏览器端 fetch() 受同源策略约束，需要服务端在 .json / .gpx 响应上带 Access-Control-Allow-Origin —— 部署包内 deploy/nginx/moto.worldstip.com.conf 已给出可直接合并的配置。

GET/map-data/index.json

全国索引。返回 31 个省份的 code、数据文件路径、路线数、城市数与文件大小（sizeKB），以及路线/途经点/城市三个总数。建议客户端缓存此文件。

GET/map-data/provinces/{code}.json

省份数据包。code 为省份拼音（如 hunan、qinghai、xizang）。包含该省全部骑行路线（含抽稀轨迹 polyline 与途经点）与该省城市聚合。单包 19KB–1934KB。

GET/map-data/routes-index.json

紧凑索引（414 KB）。1713 条路线的 id / n / t / d / days / city / citySlug / url / cs 与集合点坐标 w0，不含轨迹折线。做「按城市找路线」「按名称搜路线」时先取它，不必下载 13.5 MB 全量；命中后再回省份包取完整记录（含 p[]）。附 cities[] 城市聚合（360 城）。

GET/gpx/{id}.gpx

单条路线的 GPX 轨迹文件（application/octet-stream），id 同 routes[].id。实测 /gpx/taifushan.gpx 为 47 KB。仅市区周边实测线提供，跨市长途环线（cs=computed）无 GPX。

数据结构

省份数据包顶层结构：{ province, code, cities[], routes[] }

cities[] — 城市聚合

字段类型说明
slug / namestring城市 slug（如 changsha）与中文名（如「长沙」）
routesnumber该城市市区周边路线数（长途环线不计入城市，另挂在省的 routes 里）

routes[] — 摩托骑行路线

字段类型说明
idstring路线唯一 ID。市区周边线取自城市数据（如 taifushan、haixi-r1），跨市长途环线为 {prov}-loop{n}
nstring路线名称，如「临澧太浮山“沅澧名山”跑山线」
tstring路线类型，当前全量取值：攻山压弯 / 山林湖泊 / 文化漫游 / 咖啡驿站 / 近郊休闲 / 长途环线 / 休闲骑游 / 弯道路段 / 人文古迹 / 休闲骑行。其中「长途环线」是跨市聚合条目（节点复用站内已核验城市坐标 + 道路接口分段实算），不属于市区周边实测线
dnumber里程（公里）
daysnumber建议天数，按里程推算（每 200km 记 1 天，市区周边线恒为 1）
hstring[]亮点标签（最多 4 条）
cstring省份专属主题色（HEX），供地图渲染直接使用
p[lat,lng][]骑行轨迹 polyline（GCJ-02）。原始轨迹常达数千点，抽稀规则为每 3 点取 1、坐标保留 4 位小数；本次构建单条最多 3634 点，全量 13.5 MB
w[lat,lng][]关键途经点坐标（GCJ-02），全量 5022 个
wnstring[]途经点名称，与 w 一一对应（w[0] 恒为集合点/市政府）
city / citySlugstring所属城市名与 slug；长途环线的 city 是省名、citySlug 恒为 loops
urlstring站点内该路线的详情页路径。湖南因历史路由走 /routes/{id}/，其余省份为 /{code}/routes/{id}/
csstring文案状态，取值 verified / computed / reviewed：verified 人工撰写并经高德 POI 核验、reviewed 改写自公开资料且逐条附来源、computed 算法生成（全部长途环线）
srcsnumber该条文案引用的来源条数；cs='reviewed' 的线路在详情页展示出处，>0 才可核验
NOTE坐标系与数据质量

全部坐标为 GCJ-02（高德体系），配高德底图零偏移；配 OSM/Google 需自行转换 WGS-84。 市区周边短途路线来自实地核验的数据管线；cs='reviewed' 的文案改写自公开资料并经交叉核验， 详情页展示来源条数与出处。长途环线（cs='computed'）是跨市聚合条目，不称「实测」、也不标注来源已核验， 引用时请与市区周边短途分开口径。
