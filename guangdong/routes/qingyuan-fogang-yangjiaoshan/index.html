RIDE DISCIPLINE

骑行节奏 · 结伴纪律

本线约 48km · 建议 2 个集结点 · 约 2 次中途休息

中途休息节奏

按每 100 公里或 50 分钟驾驶强度安排一次休息，不硬撑疲劳里程。

集结点约定

每 20–30 公里约定一个集结地，清点人数、补给与休息后再统一出发。

队形与车距

不同车道错开行驶，避免同车道跟车过近；保持稳定车速与足够刹车距离，防追尾碰撞。

防掉队与次序

超短途结伴尤其注意掉队与次序，设领队与收尾、保持可视距离，路口等齐不擅自超车。

路线路径

佛冈县城石角 → Y261 乡道羊角山 → 风车山观景段 → 森波拉度假森林 → S252/G106 水头镇方向折返。

目的地介绍

看点

羊角山—福鑫风车山位于佛冈石角东南，山脊风力发电机组列阵，观景台可俯瞰佛冈县城与远山层叠，日落为黄金时段；森波拉度假森林以火山温泉与侏罗纪主题著称。

历史

佛冈明正德年间置县，取"佛祖之冈"意；水头镇温泉带近十年发展为广州北周末度假带。

人文

佛冈粉角、山溪鱼；温泉民宿与农庄构成"跑山+泡汤"的珠三角周末公式。

故事与趣事

广州东线摩友的"日落局"——下午四点半出发，山顶看完日落直接下山泡汤；雨后山路湿滑，老手都等天晴再约。

途经点 · 亮点

途经 佛冈县城石角 → 羊角山 → 森波拉度假森林 → 水头镇
亮点 风车山日落列阵 · 羊角山林道急弯 · 森波拉温泉收尾

注意事项

  • 出发前加满油，短途线也建议沿途镇级油站见站就补
  • 广东全省高速公路入口设禁摩标志、严禁驶入，本库路线全程按国道/省道/县乡道规划；清远市区未检索到禁摩通告（现行限行仅黑烟车与国三柴油货车），出发前以高德实况与当地交警发布复核
  • 3C认证头盔必戴，建议护膝手套齐全；粤北山区雨季（4-9月）路滑雾大，落石与积水路段现场判断、不抢行
  • 结伴骑行按集结点清点人数；高海拔乡道（秤架、欧家、金子山）夜间气温低，预留保暖衣物
  • 风车山后段路窄坡陡、会车困难，逆光时段减速；林区防火期进山配合检查。

路况与其他

  • 路况：县道+乡道，前段良好、后段窄陡；观景平台停车空间小。
  • 适合季节：秋 / 冬 / 春
  • 适合独行：建议结伴
