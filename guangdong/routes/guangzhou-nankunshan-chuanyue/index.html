RIDE DISCIPLINE

骑行节奏 · 结伴纪律

本线约 12km · 建议 1 个集结点 · 全程在单次休息间隔内，终点即集结

中途休息节奏

按每 100 公里或 50 分钟驾驶强度安排一次休息，不硬撑疲劳里程。

集结点约定

每 20–30 公里约定一个集结地，清点人数、补给与休息后再统一出发。

队形与车距

不同车道错开行驶，避免同车道跟车过近；保持稳定车速与足够刹车距离，防追尾碰撞。

防掉队与次序

超短途结伴尤其注意掉队与次序，设领队与收尾、保持可视距离，路口等齐不擅自超车。

路线路径

广州市政府广场 → G105国道北行 → 从化城区方向 → 南昆山盘山公路 → 南昆山山顶段 → 原路返回。

目的地介绍

看点

南昆山位于从化区北部与龙门县交界，主峰海拔1228米，为珠三角最高峰；盘山公路蜿蜒至山顶，沿途瀑布溪流、原始森林茂密，山顶可观云海与珠三角平原远眺，被誉为"北回归线上的绿洲"。

历史

南昆山古称"南昆"，清代为从化与龙门界山；历代为客家聚居地，山顶有客家村落遗迹。

人文

南昆山区域客家聚居，客家酿豆腐与竹筒饭为在地味觉；南昆山竹笋与蜂蜜为知名特产。

故事与趣事

广东跑山圈把南昆山当"珠三角跑山成年礼"——与肇庆鼎湖山、惠州罗浮山并称"广东三大跑山"；山顶云海要看运气（秋冬清晨概率最高）；老手提醒"盘山段上坡靠右、不借道、不超车；从化加满油，山上无加油站"。

注意事项

  • 广州市区全天禁摩（2003年起），违规罚款+扣车风险；本库路线均在增城/从化/花都等外围区规划，从市区出发需走国道/省道避开禁行区域
  • 出发前加满油，短途线也建议沿途镇级油站见站就补
  • 增城/从化等外围区实际执行较松但仍有被查风险，出发前以高德实况与当地交警发布复核
  • 3C认证头盔必戴，建议护膝手套齐全；南昆山/从化山区雨季（5-9月）路滑雾大，落石与积水路段现场判断、不抢行
  • 南昆山盘山段弯多路窄、会车困难，新手勿单独挑战；周末从化方向车流大，建议早出避峰；山上无加油站，从化必须加满。

路况与其他

  • 适合季节：春 / 秋 / 冬
