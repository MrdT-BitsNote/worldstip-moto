RIDE DISCIPLINE

骑行节奏 · 结伴纪律

本线约 114km · 建议 5 个集结点 · 约 3 次中途休息

中途休息节奏

按每 100 公里或 50 分钟驾驶强度安排一次休息，不硬撑疲劳里程。

集结点约定

每 20–30 公里约定一个集结地，清点人数、补给与休息后再统一出发。

队形与车距

不同车道错开行驶，避免同车道跟车过近；保持稳定车速与足够刹车距离，防追尾碰撞。

防掉队与次序

超短途结伴尤其注意掉队与次序，设领队与收尾、保持可视距离，路口等齐不擅自超车。

路线路径

惠州市人民政府 → G205国道北行 → 龙门县 → 南昆山盘山公路 → 南昆山国家森林公园 → 原路返回。

目的地介绍

看点

南昆山位于龙门县，海拔1228米，为"北回归线上的绿洲"；盘山公路连续S弯爬升至山顶，山顶竹海与云海交织；原始森林覆盖率极高，空气清冽。

历史

南昆山自唐代即为岭南名山，历代文人墨客题刻众多；近年发展为森林度假胜地。

人文

龙门为客家聚居区，龙门胡须鸡与龙门米饼为在地味觉；南昆山茶叶与南昆山蜂蜜为特产。

故事与趣事

珠三角跑山圈把南昆山当"跑山圣地"——弯道节奏感强、山顶竹海要看运气（秋冬清晨概率最高）；老手提醒"盘山段上坡靠右、不借道；龙门城区加满油，山上无加油站"。

注意事项

  • 惠州惠城中心区核心区全天禁摩，郊区可自由骑行；本库路线全程按国道/省道/县乡道规划，避开惠城核心区，出发前以高德实况与当地交警发布复核
  • 本线约 114km：出发前加满油，沿途镇级油站可补给
  • 广东全省高速公路入口设禁摩标志、严禁驶入，本库路线全程按国道/省道/县乡道规划
  • 3C认证头盔必戴，建议护膝手套齐全；沿海地区雨季（4-9月）路滑、台风季注意大风
  • 南昆山盘山段弯多路窄、会车困难，新手勿单独挑战；山上无加油站，龙门城区必须加满。

路况与其他

  • 路况：国道+盘山乡道，前段良好、后段窄弯多；山顶段会车需减速靠右。
  • 适合季节：春 / 秋 / 冬
  • 适合独行：建议结伴
