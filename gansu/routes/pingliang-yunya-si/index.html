骑行节奏 · 结伴纪律

本线约 128km · 建议 5 个集结点 · 约 3 次中途休息

中途休息节奏

按每 100 公里或 50 分钟驾驶强度安排一次休息，不硬撑疲劳里程。

集结点约定

每 20–30 公里约定一个集结地，清点人数、补给与休息后再统一出发。

队形与车距

不同车道错开行驶，避免同车道跟车过近；保持稳定车速与足够刹车距离，防追尾碰撞。

防掉队与次序

超短途结伴尤其注意掉队与次序，设领队与收尾、保持可视距离，路口等齐不擅自超车。

路线路径

平凉市区 → G70辅道/S304西南行 → 庄浪县南湖镇 → 云崖寺石窟群 → 关山天池朝那湫 → 陈家洞（可选） → 宿庄浪 → 原路返回。

目的地介绍

看点

云崖寺始凿于北魏，现存窟龛160余个、造像1300余尊，为国家级森林公园；关山大景区含云崖寺、朝那湫、陈家洞、葛家洞、红崖湾五片区。

历史

云崖寺由北魏至明代持续修凿，是丝路东段佛教艺术晚期代表；朝那湫为古代祭祀龙神之渊。

人文

庄浪为"中国梯田化模范县"，梯田精神与关山牧歌并存；庄浪洋芋与苹果为特产。

故事与趣事

陇东跑山圈把S304关山段当"平凉版发卡弯挑战"——雨雾天封路概率高，出发前查路况；老手提醒"云崖寺与朝那湫一天玩不完，宿庄浪最从容"。

注意事项

  • 本线约 128km，单箱油难以往返：崆峒区/泾川/庄浪/华亭县城均有中石化/中石油，进关山山区前在县城加满，S304沿线乡镇油站少
  • 甘肃省高速主干道（G22青兰/G70福银等）入口普遍设禁摩标志，本库路线全程按国道/省道/县乡道规划；平凉市区未检索到禁摩通告，出发前以高德实况与当地交警发布复核
  • 3C认证头盔必戴，建议护膝手套齐全；陇东冬季干冷多风沙，春秋早晚温差大；庄浪S304长下坡+急弯段雨天极易打滑，务必控速保持车距
  • 云崖寺门票约60元；关山段海拔2000米以上早晚冷；长下坡用低挡控速，避免刹车热衰减。
