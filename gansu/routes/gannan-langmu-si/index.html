骑行节奏 · 结伴纪律

中途休息节奏

按每 100 公里或 50 分钟驾驶强度安排一次休息，不硬撑疲劳里程。

集结点约定

每 20–30 公里约定一个集结地，清点人数、补给与休息后再统一出发。

队形与车距

不同车道错开行驶，避免同车道跟车过近；保持稳定车速与足够刹车距离，防追尾碰撞。

防掉队与次序

超短途结伴尤其注意掉队与次序，设领队与收尾、保持可视距离，路口等齐不擅自超车。

路线路径

合作市 → G213南下 → 碌曲县城（则岔石林方向） → 郎木寺镇 → 纳摩大峡谷 → 宿郎木寺 → 原路返回。

目的地介绍

看点

郎木寺镇居甘川交界，赛赤寺依山而建可望红石崖日落；格尔底寺含肉身佛殿与纳摩大峡谷，谷内白龙江源头潺潺。

历史

两寺均建于清乾隆年间；郎木寺在安多藏语中意为"虎穴仙女"，传说仙女在此降伏猛虎。

人文

镇上有丽莎西餐厅等传奇背包客老店；藏式牦牛汤锅与青稞酒是夜生活主角。

故事与趣事

摩友把郎木寺当"甘南川北的十字路口"——向南可续骑若尔盖花湖与黄河九曲；老手提醒"清晨爬上红石崖看炊烟绕金顶，是郎木寺的封面镜头"。

注意事项

  • 本线约 163km，单箱油难以往返：合作/夏河/碌曲/迭部/玛曲县城均有中石化/中石油，进草原与扎尕那、洛克之路前在县城加满，乡镇油站傍晚即关门
  • 甘肃省高速主干道原则上禁摩，本库路线全程按国道/省道/县乡道规划；甘南州全境未检索到禁摩通告，以高德实况与当地交警发布复核
  • 3C认证头盔必戴，建议护膝手套齐全；甘南平均海拔约3000米，垭口超3500米，慢行防高反、备保暖层；6-9月为最佳骑行季，10月后草原早雪、冬季多数山路封闭
  • 藏区骑行尊重当地习俗：寺院顺时针绕行、经幡玛尼堆勿踩踏、拍僧人与信众前先征得同意；草原上遇牦牛群减速绕行不鸣笛
  • 赛赤寺门票约30元、格尔底寺约30元；郎木寺镇住宿旺季提前订，海拔约3300米慢行防高反。
