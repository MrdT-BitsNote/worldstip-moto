RIDE DISCIPLINE

骑行节奏 · 结伴纪律

本线约 73km · 建议 3 个集结点 · 约 2 次中途休息

中途休息节奏

按每 100 公里或 50 分钟驾驶强度安排一次休息，不硬撑疲劳里程。

集结点约定

每 20–30 公里约定一个集结地，清点人数、补给与休息后再统一出发。

队形与车距

不同车道错开行驶，避免同车道跟车过近；保持稳定车速与足够刹车距离，防追尾碰撞。

防掉队与次序

超短途结伴尤其注意掉队与次序，设领队与收尾、保持可视距离，路口等齐不擅自超车。

路线路径

武汉市人民政府 → 岱黄高速/黄陂城区 → 木兰山风景区 → 石泡线盘山段 → 原路或经黄陂乡道返回。

目的地介绍

看点

木兰山位于黄陂区北部，海拔582米，为道教圣地，山顶有金顶、玉皇阁等古建筑群；石泡线为木兰山周边盘山公路，连续发卡弯与S弯交替，是武汉摩友跑山练车经典线路。

历史

木兰山因花木兰传说得名，唐代已有道教宫观建设；明清时期成为鄂北道教中心，现存古建筑多为清代所建。

人文

黄陂区为木兰故里，木兰传说为国家级非遗；黄陂三合（鱼丸、肉丸、肉糕）为在地味觉。

故事与趣事

武汉跑山圈把石泡线当"魔鬼训练场"——坡陡出弯视距短，老手规矩是上坡靠右、不借道、不超车；周末车队多在前一天夜宿黄陂城区，次日一早攻山。

注意事项

  • 本线约 73km：出发前加满油，远郊乡道补给点间距大，建议自带饮水
  • 武汉三环内全天禁摩（罚200元+扣3分），本库路线全程从远郊出发、不进入三环；途经三环边界时注意标志，以高德实况与武汉交警发布复核
  • 3C认证头盔必戴，建议护膝手套齐全；大别山余脉雨季（5-9月）路滑雾大，落石与积水路段现场判断、不抢行
  • 石泡线坡陡弯急、部分路段无护栏，新手勿单独挑战；周末黄陂城区车流大，建议早出避峰。

路况与其他

  • 路况：省道+盘山乡道，前段良好、石泡线后段窄陡多弯；山顶段会车需减速靠右。
  • 适合季节：春 / 秋 / 冬
  • 适合独行：建议结伴
