RIDE DISCIPLINE

骑行节奏 · 结伴纪律

本线约 86km · 建议 3 个集结点 · 约 2 次中途休息

中途休息节奏

按每 100 公里或 50 分钟驾驶强度安排一次休息，不硬撑疲劳里程。

集结点约定

每 20–30 公里约定一个集结地，清点人数、补给与休息后再统一出发。

队形与车距

不同车道错开行驶，避免同车道跟车过近；保持稳定车速与足够刹车距离，防追尾碰撞。

防掉队与次序

超短途结伴尤其注意掉队与次序，设领队与收尾、保持可视距离，路口等齐不擅自超车。

路线路径

木鱼镇集合 → 盘山公路西行 → 翻越山脊 → 大九湖湿地 → 原路返回。

目的地介绍

看点

大九湖位于神农架西部，海拔1700米的高山湿地；九个湖泊如镜、晨雾翻腾，被誉为"华中呼伦贝尔"。

历史

大九湖因九个湖泊而得名，古为川鄂古道经过之地。

人文

坪阡古镇土家族聚居，腊肉与懒豆腐为在地风物。

故事与趣事

湖北跑山圈把大九湖叫"晨雾线"——清晨六个湖泊雾气翻腾如入仙境；老手提醒"翻山脊段雾气大、能见度低，开雾灯慢行"。

途经点 · 亮点

途经 木鱼镇 → 大九湖
亮点 华中唯一高山湿地 · 九个湖泊如镜 · 晨雾翻腾如仙境 · 神农架最静谧终点

注意事项

  • 本线约 86km：出发前加满油，山区乡道补给点间距大，建议自带饮水
  • 湖北全省高速公路入口设禁摩标志、严禁驶入，本库路线全程按国道/省道/县乡道规划；神农架林区未检索到禁摩通告，出发前以高德实况与当地交警发布复核
  • 3C认证头盔必戴，建议护膝手套齐全；神农架海拔高、雨季（5-9月）路滑雾大，落石与积水路段现场判断、不抢行
  • 神农架景区联票269元含六大景区，有效期5天；金丝猴岭禁止投喂
  • 大九湖需购景区联票；晨雾最佳观赏时间为6-8点，建议住坪阡古镇早起。

路况与其他

  • 路况：景区公路，铺装良好；翻越山脊段弯急坡陡、雾气大。
  • 适合季节：春 / 夏 / 秋
  • 适合独行：建议结伴
