骑行节奏 · 结伴纪律

中途休息节奏

按每 100 公里或 50 分钟驾驶强度安排一次休息，不硬撑疲劳里程。

集结点约定

每 20–30 公里约定一个集结地，清点人数、补给与休息后再统一出发。

队形与车距

不同车道错开行驶，避免同车道跟车过近；保持稳定车速与足够刹车距离，防追尾碰撞。

防掉队与次序

超短途结伴尤其注意掉队与次序，设领队与收尾、保持可视距离，路口等齐不擅自超车。

路线路径

延安城区 → G341/省道西行 → 志丹县城 → 保安革命旧址 → 吴起县 → 长征纪念园 → 夜宿吴起 → 原路返回。

目的地介绍

看点

吴起长征纪念园为国家4A景区，含长征胜利纪念碑与纪念馆；志丹县存保安革命旧址与抗日红军大学旧址。

历史

1935年10月中央红军抵达吴起镇，"切尾巴战役"歼灭追敌，长征宣告胜利结束；1936年保安（志丹）曾为中共中央驻地。

人文

志丹为将军县，刘志丹精神与陕北民歌（信天游）交织；吴起剁荞面为在地味觉名片。

故事与趣事

红色骑摩友把志丹—吴起当"长征两日"——第一日志丹宿县城，第二日吴起纪念园收尾；老手提醒"黄土梁峁段侧风大，桥面与垭口握稳车把"。

注意事项

  • 本线约 162km，单箱油难以往返：延安城区及宜川、延川、黄陵、志丹、吴起县城均有中石化/中石油，黄土区乡道油站稀少，进沟前必须加满
  • 延安市区部分主干道对摩托车限行：双拥大道摩托车禁入主路、只能走两侧辅路；出发前查"延安交警"公众号确认管控路段；陕西全省高速禁摩，本库路线全部按国道/省道/县乡道规划
  • 3C认证头盔必戴，建议护膝手套齐全；黄土高原4-9月多暴雨，沟壑路段塌方与泥浆风险高，雨后不进土路；冬季风大路滑
  • 志丹、吴起县城住宿充足；黄土区暴雨后乡道泥泞，勿偏离铺装路面。
