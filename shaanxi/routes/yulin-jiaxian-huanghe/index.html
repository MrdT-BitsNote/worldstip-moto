骑行节奏 · 结伴纪律

本线约 124km · 建议 5 个集结点 · 约 3 次中途休息

中途休息节奏

按每 100 公里或 50 分钟驾驶强度安排一次休息，不硬撑疲劳里程。

集结点约定

每 20–30 公里约定一个集结地，清点人数、补给与休息后再统一出发。

队形与车距

不同车道错开行驶，避免同车道跟车过近；保持稳定车速与足够刹车距离，防追尾碰撞。

防掉队与次序

超短途结伴尤其注意掉队与次序，设领队与收尾、保持可视距离，路口等齐不擅自超车。

路线路径

榆林城区 → G210南下 → 佳县县城 → 白云山 → 香炉寺 → 沿黄公路佳县段 → 夜宿佳县 → 原路返回。

目的地介绍

看点

白云山道观群建于明万历年间，依山就势53座庙宇，为西北最大道教圣地；香炉寺立于黄河绝壁孤石之上，仅3米石桥相连。

历史

佳县古称葭州，明末农民军李自成曾在此转战；《东方红》诞生于佳县——作曲家李有源即佳县人。

人文

佳县为红枣之乡，千年枣园与枣木工艺为在地名片；白云山道教音乐为国家级非遗。

故事与趣事

陕北摩友把佳县当"黄河两日"——第一天白云山，傍晚香炉寺看落日，第二天沿黄公路北返；老手提醒"香炉寺石桥窄，摩托车停县城步行上寺"。

注意事项

  • 本线约 124km，单箱油难以往返：榆林城区及靖边、神木、佳县县城均有中石化/中石油，沙漠与黄土区乡道油站稀少，出城前务必加满
  • 榆林中心城区限行为货车/专项作业车（榆政发〔2022〕10号），未检索到摩托车禁行通告；陕西全省高速禁摩，本库路线全部按国道/省道/县乡道规划
  • 3C认证头盔必戴，建议护膝手套齐全；塞上春季风沙大（3-5月），备防风镜与魔术头巾；夏季紫外线强，冬季零下20℃不宜长途骑行
  • 白云山庙会（农历四月初八）人流极大；沿黄公路临崖段勿夜间骑行。
