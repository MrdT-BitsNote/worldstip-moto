骑行节奏 · 结伴纪律

本线约 164km · 建议 7 个集结点 · 约 3 次中途休息

中途休息节奏

按每 100 公里或 50 分钟驾驶强度安排一次休息，不硬撑疲劳里程。

集结点约定

每 20–30 公里约定一个集结地，清点人数、补给与休息后再统一出发。

队形与车距

不同车道错开行驶，避免同车道跟车过近；保持稳定车速与足够刹车距离，防追尾碰撞。

防掉队与次序

超短途结伴尤其注意掉队与次序，设领队与收尾、保持可视距离，路口等齐不擅自超车。

路线路径

榆林城区 → G210/S302西行 → 靖边县城 → 龙洲镇 → 波浪谷景区 → 夜宿龙洲/靖边 → 原路返回。

目的地介绍

看点

波浪谷丹霞形成于9600万年前的白垩纪，红砂岩层理如凝固波浪，一线天、水上丹霞与火焰丹霞为三大主景。

历史

靖边为明代靖边卫，长城穿境；统万城（大夏国都，匈奴族唯一都城遗址）在县北，可与波浪谷连游。

人文

靖边跑驴与陕北说书为国家级非遗；风干羊肉剁荞面为在地味觉名片。

故事与趣事

陕北摩友把波浪谷当"摄影远征"——傍晚日落与清晨侧光是两个拍摄窗口，多数摩友选择夜宿龙洲镇两日往返；老手提醒"丹霞区手机信号弱，结伴出行"。

途经点 · 亮点

途经 榆林·世纪广场 → 靖边县城 → 波浪谷景区
亮点 红砂岩波浪纹理 · 日落丹霞 · 毛乌素沙地南缘公路 · 水上丹霞一线天

注意事项

  • 本线约 164km，单箱油难以往返：榆林城区及靖边、神木、佳县县城均有中石化/中石油，沙漠与黄土区乡道油站稀少，出城前务必加满
  • 榆林中心城区限行为货车/专项作业车（榆政发〔2022〕10号），未检索到摩托车禁行通告；陕西全省高速禁摩，本库路线全部按国道/省道/县乡道规划
  • 3C认证头盔必戴，建议护膝手套齐全；塞上春季风沙大（3-5月），备防风镜与魔术头巾；夏季紫外线强，冬季零下20℃不宜长途骑行
  • 波浪谷景区分A/B/C区，徒步总量约6-8公里；砂岩脆弱勿踩踏纹理区；龙洲镇农家乐住宿为主，国庆需预订。
