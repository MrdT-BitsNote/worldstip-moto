RIDE DISCIPLINE

骑行节奏 · 结伴纪律

本线约 68km · 建议 3 个集结点 · 约 2 次中途休息

中途休息节奏

按每 100 公里或 50 分钟驾驶强度安排一次休息，不硬撑疲劳里程。

集结点约定

每 20–30 公里约定一个集结地，清点人数、补给与休息后再统一出发。

队形与车距

不同车道错开行驶，避免同车道跟车过近；保持稳定车速与足够刹车距离，防追尾碰撞。

防掉队与次序

超短途结伴尤其注意掉队与次序，设领队与收尾、保持可视距离，路口等齐不擅自超车。

路线路径

北碚城区 → 金刚碑古村 → 缙云山东坡盘山 → 天府镇 → 静观镇 → 柳荫镇 → 偏岩古镇 → 胜天湖 → 金刀峡方向 → 返回。

目的地介绍

看点

1314环线覆盖嘉陵江以东5镇16村，最高海拔1314m；串联金刚碑（无滤镜古村）、缙云山东坡盘山、天府镇起点、静观田园、柳荫「又见柳荫」文化品牌、偏岩古镇（清代场镇）、胜天湖（摄影水库）等节点。

历史

偏岩古镇始建于清代，是嘉陵江支流上的商贸场镇；金刚碑古村因张飞古道而兴，近年成为无滤镜拍照圣地。

人文

偏岩古镇豆腐是北碚摩友的标配午餐；静观镇以花卉苗木闻名；柳荫镇「又见柳荫」为近年乡村振兴文化品牌。

故事与趣事

摩友把1314叫「北碚的浪漫环线」——最高海拔1314m谐音"一生一世"，情侣骑手爱来打卡；老手建议逆时针走，先攻缙云山东坡的弯、再在偏岩吃豆腐收尾。

注意事项

  • 出发前加满油，北碚近郊补给方便，沿途镇级加油站密集
  • 重庆全市高速公路禁摩（标志执法），本线全程走国道/省道/县乡道；北碚城区无禁摩通告，出发前以高德实况与当地交警发布复核
  • 3C认证头盔必戴，建议护膝手套齐全；缙云山海拔不高但弯密，注意会车
  • 结伴骑行按集结点清点人数；金刚碑古村路窄限速，推车步行段勿骑行
  • 1314环线为2025年官方推出产品，沿途标识系统完善；周末偏岩古镇自驾较多。
