RIDE DISCIPLINE

骑行节奏 · 结伴纪律

本线约 83km · 建议 3 个集结点 · 约 2 次中途休息

中途休息节奏

按每 100 公里或 50 分钟驾驶强度安排一次休息，不硬撑疲劳里程。

集结点约定

每 20–30 公里约定一个集结地，清点人数、补给与休息后再统一出发。

队形与车距

不同车道错开行驶，避免同车道跟车过近；保持稳定车速与足够刹车距离，防追尾碰撞。

防掉队与次序

超短途结伴尤其注意掉队与次序，设领队与收尾、保持可视距离，路口等齐不擅自超车。

路线路径

石柱土家族自治县人民政府（南宾镇集合） → 鱼池镇·千野草场 → 黄水国家森林公园 → 大风堡（黄水镇山脊） → 沿林区公路折返。

目的地介绍

看点

黄水国家森林公园与大风堡为石柱东北的成片原始林与亚高山草甸，千野草场（鱼池镇）是高山草甸景观；三地连片构成渝东重要的"林海+草场"避暑带。

历史

黄水、大风堡一带旧为石柱土家族自治县的林场地界，2000年代陆续开发为森林公园与度假区。

人文

土家腊肉、咂酒与高山野菜是东北线的味觉标签；夏季避暑人群集中。

故事与趣事

石柱骑手把黄水叫"天然空调"——一上山就凉；老手提醒林区窄会车靠右、油站间距大。

途经点 · 亮点

途经 石柱土家族自治县人民政府 → 千野草场 → 黄水国家森林公园 → 大风堡
亮点 黄水国家森林公园 · 大风堡原始林 · 千野草场高山草甸 · 夏季林海清凉

注意事项

  • 本线约 83km：出发前加满油，途经镇级油站见站就补
  • 重庆全市高速公路禁摩（标志执法），本线全程走国道/省道/县乡道，不驶入高速
  • 丰都、忠县、石柱境内国道与场镇路段减速慢行；方斗山、七曜山、黄水林区盘山段弯密坡陡、雾天视距短，会车靠右
  • 名山鬼城、石宝寨、西沱古镇、黄水景区核心区步行化，请停在外围停车场；南天湖、大风堡高海拔夜间低温，带好保暖
  • 3C认证头盔必戴，建议护膝手套齐全；结伴骑行按集结点清点人数
  • 黄水、大风堡为高山景区，夜间低温，带好保暖；防火期管控，进山配合检查。

路况与其他

  • 路况：县乡道+林区公路，铺装良好、弯缓坡长；高海拔雾天视距短、信号弱。
  • 适合季节：春 / 夏 / 秋
  • 适合独行：建议结伴
