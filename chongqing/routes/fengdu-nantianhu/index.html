RIDE DISCIPLINE

骑行节奏 · 结伴纪律

本线约 79km · 建议 3 个集结点 · 约 2 次中途休息

中途休息节奏

按每 100 公里或 50 分钟驾驶强度安排一次休息，不硬撑疲劳里程。

集结点约定

每 20–30 公里约定一个集结地，清点人数、补给与休息后再统一出发。

队形与车距

不同车道错开行驶，避免同车道跟车过近；保持稳定车速与足够刹车距离，防追尾碰撞。

防掉队与次序

超短途结伴尤其注意掉队与次序，设领队与收尾、保持可视距离，路口等齐不擅自超车。

路线路径

丰都县人民政府（平都大道集合） → 雪玉洞（龙河镇） → 九重天景区（102省道） → 南天湖（仙女湖镇湖岸） → 沿盘山公路折返。

目的地介绍

看点

南天湖为丰都东南的高山湖泊，环湖草甸与森林相映，是渝东知名避暑地；九重天为天坑地缝式峡谷景区；雪玉洞为峡谷中的钙化溶洞。

历史

南天湖一带因高海拔气候开发为旅游度假区；雪玉洞、九重天为近年地质科普与山地旅游热点。

人文

高山土产、烤全羊与湖区鱼是夏季客流节点的味觉标签；场镇豆花普遍。

故事与趣事

丰都骑手把南天湖叫"后山空调"——夏天一上山就凉；老手提醒盘山段雾大、会车靠右。

途经点 · 亮点

途经 丰都县人民政府 → 雪玉洞 → 九重天 → 南天湖
亮点 南天湖高山湖 · 九重天天坑草场 · 雪玉洞溶洞 · 夏季清凉长线

注意事项

  • 本线约 79km：出发前加满油，途经镇级油站见站就补
  • 重庆全市高速公路禁摩（标志执法），本线全程走国道/省道/县乡道，不驶入高速
  • 丰都、忠县、石柱境内国道与场镇路段减速慢行；方斗山、七曜山、黄水林区盘山段弯密坡陡、雾天视距短，会车靠右
  • 名山鬼城、石宝寨、西沱古镇、黄水景区核心区步行化，请停在外围停车场；南天湖、大风堡高海拔夜间低温，带好保暖
  • 3C认证头盔必戴，建议护膝手套齐全；结伴骑行按集结点清点人数
  • 南天湖、九重天为高山景区，夜间低温，带好保暖与雨具；旺季停车场紧张。

路况与其他

  • 路况：省道+盘山公路，铺装良好、弯多坡长；高海拔雾天视距短。
  • 适合季节：春 / 夏 / 秋
  • 适合独行：建议结伴
