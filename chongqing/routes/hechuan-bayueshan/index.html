RIDE DISCIPLINE

骑行节奏 · 结伴纪律

本线约 69km · 建议 3 个集结点 · 约 2 次中途休息

中途休息节奏

按每 100 公里或 50 分钟驾驶强度安排一次休息，不硬撑疲劳里程。

集结点约定

每 20–30 公里约定一个集结地，清点人数、补给与休息后再统一出发。

队形与车距

不同车道错开行驶，避免同车道跟车过近；保持稳定车速与足够刹车距离，防追尾碰撞。

防掉队与次序

超短途结伴尤其注意掉队与次序，设领队与收尾、保持可视距离，路口等齐不擅自超车。

路线路径

铜梁区人民政府（巴川集合） → 虎峰镇（补给） → 巴岳山（山脊盘山段） → 西河镇（场镇收尾） → 沿县道折返。

目的地介绍

看点

巴岳山为铜梁南部的低山山体，丹霞地貌与森林步道相间，登顶可远眺涪江平原；西河镇在山脚水网平坝，老场镇烟火浓。

历史

巴岳山旧为巴渝名山，寺观与古道遗存较多；西河为铜梁南部传统农业镇。

人文

山货、竹笋与铜梁龙舞文化是南翼线的底色；场镇豆花饭普遍。

故事与趣事

铜梁南翼车队把巴岳山叫"小峨眉"——一圈就能下来；老手提醒山脊窄会车靠右。

途经点 · 亮点

途经 铜梁区人民政府 → 虎峰镇 → 巴岳山 → 西河镇
亮点 巴岳山丹霞森林 · 虎峰—西河乡道 · 低山弯线 · 南翼就近攻山

注意事项

  • 本线约 69km：出发前加满油，途经镇级油站见站就补
  • 重庆全市高速公路禁摩（标志执法），本线全程走国道/省道/县乡道，不驶入高速
  • 合川、铜梁、潼南境内国道与场镇路段减速慢行；巴岳山盘山段弯密坡陡、雾天视距短，会车靠右
  • 古镇核心区步行化，请停在外围停车场；钓鱼城、双江古镇为文保与开放街区，服从现场管理
  • 3C认证头盔必戴，建议护膝手套齐全；结伴骑行按集结点清点人数
  • 巴岳山景区林道与步道区分，骑行按景区指引停车；山区信号弱，结伴出行。

路况与其他

  • 适合季节：春 / 秋 / 冬
  • 适合独行：建议结伴
